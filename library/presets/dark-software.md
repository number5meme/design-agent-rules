# Deep Gray Lavender Parameter Preset

See [When to Read a Preset](index.md#when-to-read-a-preset). Record the adopted dimensions and adjusted values per the project; parameters do not dictate page composition, and adaptation follows actual content.

## Visual Parameters

| Role | Reference value |
|---|---|
| Page background | #17151f |
| Card / panel / overlay | #211e2b / #2b2738 / #353045 |
| Primary / secondary / supporting text | #f6f3fc / #d4cde3 / #b7abc9 |
| Action accent | #c4b5fd, dark foreground #202630 |
| Subtle divider / control border | #40394f / #a093b3 |
| Display heading | 80 / 56 / 40px, weight 600, line height 1.05–1.15 |
| Card title | 22px / 500 / 1.25 |
| Body / supporting text | 16px / 1.5; 14px / 1.5 |
| Button / card / large image panel corner radius | 8 / 12 / 16px |
| Spacing | 4 / 8 / 12 / 16 / 24 / 32 / 48px; major sections 96px |

Use a sans-serif font available to the project; code content can use a monospace font. Fine-tune negative letter spacing of display headings to the actual font; Chinese and fallback fonts do not directly inherit Latin letter spacing. Control borders and focus must be visible on the actual background; subtle dividers cannot serve as the only action cue.

## Status Reference

Adopt the `dark` theme in [Shared Status Pairs](status-pairs.json), following [Shared Status Usage](index.md#shared-status-usage). All four status foregrounds meet 4.5:1 on this preset's documented page, card, panel, and overlay backgrounds.
