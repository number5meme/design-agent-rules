# Bright Rounded Showcase Parameter Preset

See [When to Read a Preset](index.md#when-to-read-a-preset). Record the adopted dimensions and adjusted values per the project; parameters do not dictate page composition, and adaptation follows actual content.

## Visual Parameters

| Role | Reference value |
|---|---|
| Page and main container | #ffffff |
| Thumbnails and supporting surfaces | #f5f5f5 |
| Primary text | #202630 |
| Purchase action | #245da8, white foreground |
| Showcase page primary action | #202630, white foreground #ffffff |
| Secondary action | Transparent background, text #202630, necessary outline #737d8c; for the light surfaces in this table |
| Control / regular card / large image card corner radius | 8 / 16 / 32px |
| Action buttons | Pill-shaped, text 14px / 700, horizontal padding reference 30px |
| Body | 16px / 400 / 1.5; supporting text 14px / 1.43 |
| Headings | 64 / 48 / 36 / 24px, weight reference 500 |
| Spacing | 8 / 12 / 16 / 24 / 32px; section spacing 64–80px |

Use a sans-serif font available to the project. Button height reference 48px, input 44px; do not clip when text grows. Showcase and purchase may use different emphasis, and actions within the same task stay consistent.

## Responsive Starting Point

| Width | Layout |
|---|---|
| Below 768px | Gallery and purchase area stacked vertically; feature cards in one column; heading reference 32–36px |
| 768–1023px | Purchase area still below the gallery; feature cards may be two columns; heading reference 48px |
| From 1024px | Gallery and purchase summary in two columns; feature cards in three or four columns by content; heading max reference 64px |

## Status Reference

Adopt the `light` theme in [Shared Status Pairs](status-pairs.json), following [Shared Status Usage](index.md#shared-status-usage). All four status foregrounds meet 4.5:1 on this preset's documented light page, main container, thumbnails, and supporting surfaces.
