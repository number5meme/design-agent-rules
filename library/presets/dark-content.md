# Graphite Mint Parameter Preset

See [When to Read a Preset](index.md#when-to-read-a-preset). Record the adopted dimensions and adjusted values per the project; parameters do not dictate page composition, and adaptation follows actual content.

## Visual Parameters

| Role | Reference value |
|---|---|
| Page background | #141b23 |
| Cards and sidebar | #202a35 |
| Interactive surface | #2a3643 |
| Overlay surface | #344252 |
| Primary / secondary text | #f4f7fb / #c0cbd8 |
| Playback and current action accent | #8bd5ad, dark foreground #141b23 |
| Border | #8f9fb2; emphasis border #c5d2e1 |
| Body / supporting text / section title | 16 / 14 / 24px |
| Regular / emphasis weight | 400 / 700 |
| Card / panel corner radius | 6–8 / 12–20px |
| Search and filters | Pill-shaped; play buttons may be circular |
| Spacing | 4 / 8 / 12 / 16 / 20 / 24px |

Brightness increases from page → card → interactive surface → overlay; this hierarchy is this preset's starting point. Use a sans-serif font available to the project; body line height reference 1.5. Distinguish overlays primarily through surface lightness and borders, adding shadows when necessary; heavy shadows are not required on all dark cards.

## Status Reference

Adopt the `dark` theme in [Shared Status Pairs](status-pairs.json), following [Shared Status Usage](index.md#shared-status-usage). All four status foregrounds meet 4.5:1 on this preset's documented page, card/sidebar, interactive surface, and overlay backgrounds.
