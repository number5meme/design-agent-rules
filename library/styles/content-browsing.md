# Content Browsing Design Method

First distinguish browsing, searching, comparing, and continuous playback; whether cover, text, or preview carries the main information is decided by content type, and a content library does not automatically gain playback.

## Content and Actions

- When visual recognition dominates, a grid can be used; when field comparison dominates, a list can be used; content can also be organized into sections.
- Open, play, favorite, and more actions each have their own responsibility; avoid outer containers and inner buttons triggering twice.
- Present now playing, selected, hover, and focus separately; necessary actions on touch must not appear only on hover.
- When continuous playback is needed, arrange playback controls by device and task; when space is limited, keep key controls and place secondary items in reachable positions.

## Visuals and Adaptation

Choose light/dark theme and accent color by brand, content, and environment. When using dark, build hierarchy with surface, border, and text contrast; do not fix accent color or control shape. Focus and states must not rely only on hard-to-distinguish colors.

Adjust navigation and content density by readability. When fixed controls and bottom navigation coexist, define each one's spacing; check long titles, missing images, load failures, content switching, return position, and keyboard and touch operation.
