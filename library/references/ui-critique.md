# UI Critique

Use for a requested design review or a primary-flow design check after implementation. Apply only the relevant checks. Identify the primary action and inspect the actual screens and states first. Form your observations before reading automated findings, then reproduce or qualify what the tools report.

Walk the flow from two or three relevant user perspectives when their needs differ. Identify the step, observed obstacle, consequence, and evidence. Label simulated walkthroughs as such. Use Nielsen's heuristics as optional prompts, for example whether users can see system status, recover from an error, or recognize an available action. At a crowded decision, check whether people can distinguish options and predict the result. Option count alone does not establish a defect.

For review only, give findings in the reply and save a record only if requested. Report the most consequential findings with reproduction steps and verification gaps.
