# Design System Export

## Exporting DESIGN.md

When the recipient requests this format, generate the export from confirmed project decisions and variables using the [Google DESIGN.md specification](https://github.com/google-labs-code/design.md/blob/main/docs/spec.md). Verify the revision required by the recipient and record the version or commit actually used for export. Follow that revision's supported structure and section order. If you cannot verify the revision, mark format compatibility as unverified. Declare intentionally omitted sections and their reasons, and use concrete do and avoid examples for easily misapplied rules. Check token references against the source. Keep the project record as the source for subsequent exports.
