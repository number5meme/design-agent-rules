# Project Record Templates

Reuse the project's existing equivalent records; small tasks can combine them into one; for responsibilities, see [Record Ownership](../../standards/task-scope.md#record-ownership). Adjust links after copying; empty sections need not be kept.

| Template | Maintains |
|---|---|
| [Scope](brief.md) | Current goal, scope, and success criteria |
| [Design](design.md) | Current design decisions and rationale |
| [Review](review.md) | Feedback, issues, and actual verification |
| [Handoff](handoff.md) | Deliverable entry points, incomplete items, and next steps |

Handle history archiving per [Current Records and History](../../standards/task-scope.md#current-records-and-history); do not pre-create empty history files.
