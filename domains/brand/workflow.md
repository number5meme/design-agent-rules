# Brand and Character Workflow

Read by task: [Workflow](workflow.md) · [Method](design.md) · [Acceptance](quality.md). For local edits, read only the affected sections.

## Scope and Baseline

Determine this task's assets, quantity, format, and editability requirements per [Task Scope](../../standards/task-scope.md). Check whether an existing logo or character is the current baseline, distinguishing keeping, local edit, and redesign; do not default to a full visual system, character pack, or showcase mockups.

## Production and Extension

Translate purpose and audience into form, typography, and asset choices per the [Design Method](design.md). Produce the views, expressions, and materials that depend on the main character only after it is settled; follow agreements when a stage review is needed, otherwise continue work within the authorized scope. For set extensions, reference [Series Visuals](../../standards/series-visuals.md).

## Verification and Delivery

Check standalone assets and applied results per [Brand Acceptance](quality.md); register mockups and finals separately. After a baseline change, recheck affected materials; the handoff record notes actual formats, versions, and unverified items.
