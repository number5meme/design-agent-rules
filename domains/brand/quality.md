# Brand and Character Acceptance

Read by task: [Workflow](workflow.md) · [Method](design.md) · [Acceptance](quality.md). For local edits, read only the affected sections.

| Check | Criteria and evidence |
|---|---|
| Identity and text | Check name, spelling, logo, and character features against the valid baseline; no mismatches or unauthorized changes |
| Logo recognizability | View at the actual minimum application size and on agreed single-color and reversed backgrounds; outline and text remain recognizable; for the design method, see [Logo](design.md#logo) |
| Character extension | Check body shape, facial features, patterns, accessories, and left-right relationships across views side by side; differences match agreed actions and do not change identity |
| System and applications | Colors, typography, and combination rules match actual assets; affected materials use the current baseline; for set checks, see [Series Visuals](../../standards/series-visuals.md#set-checks) |
| File capability | Standalone assets and mockups are each accessible; required vector paths, alpha channels, and editable objects can actually be checked; bitmaps do not pose as vectors |

Check informational text in applied materials per the [static visuals readability baseline](../../standards/defaults.md#static-visuals); the logo's own exception does not extend to ordinary copy. For general export and verification conclusions, see [Design File and Export Acceptance](../../standards/quality.md#design-file-and-export-acceptance).
