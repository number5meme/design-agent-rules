# Product Detail Acceptance

Read by task: [Workflow](workflow.md) · [Method](design.md) · [Acceptance](quality.md). For local edits, read only the affected sections.

| Check | Criteria and evidence |
|---|---|
| Product fidelity | Check shape, color, material, markings, and visible text against actual images and confirmed information; concept assets are not called real photos |
| Claims and evidence | Selling points, performance, specs, and comparison conditions are traceable; image details support adjacent descriptions; no fabricated units or sizes |
| Image-text and continuity | Module tasks are clear and images match text; check reading, long-image continuity, cropping, and duplicate content at the target mobile display size |
| Output and platform | Check size, format, and platform rules for the current target; when editability is agreed, check the corresponding objects; production annotations, color values, prompts, and layout guides stay only in agreed spec images, not mixed into customer-facing images |

Verify informational text and key graphics per the [static visuals readability baseline](../../standards/defaults.md#static-visuals); file checks follow [Design File and Export Acceptance](../../standards/quality.md#design-file-and-export-acceptance).
