# Product Detail Visuals Workflow

Read by task: [Workflow](workflow.md) · [Method](design.md) · [Acceptance](quality.md). For local edits, read only the affected sections.

## Scope and Inputs

Distinguish product main images, detail module images, page code, and copy; confirm this task's deliverables per [Task Scope](../../standards/task-scope.md). Collect real product information and baseline images, and clarify the placement carrier and editability requirements.

## Organization and Production

Organize buyer questions, claims, and evidence per the [Design Method](design.md), then produce image-text modules. For layout and asset production, read the [Poster Method](../poster/design.md) selectively; for set output, use [Series Visuals](../../standards/series-visuals.md), without rerunning multiple workflows in full.

## Verification and Delivery

Check fidelity, facts, reading, and output specs per [Product Detail Acceptance](quality.md). Do not fill factual gaps with generated assets presented as conclusions; deliver the agreed module images or source files, and do not add a product web page by default.
