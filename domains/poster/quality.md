# Poster Acceptance

Read by task: [Workflow](workflow.md) · [Method](design.md) · [Acceptance](quality.md). For local edits, read only the affected sections.

Use this checklist as the primary acceptance for posters, covers, and showcase images. From [Quality and Acceptance](../../standards/quality.md), apply shared evidence requirements and only the relevant asset, editability, and export checks; do not load interface or runtime checks for static artwork.

Check numeric thresholds for text and key graphics, final-size determination, and print/projection boundaries per the [static visuals readability baseline](../../standards/defaults.md#static-visuals); record color measurements and the actual output environment, and do not pass based on subjective readability alone.

- Check applicable content such as title, names, time, place, and price for omissions, typos, and unconfirmed additions.
- Visual inspection at original size. Open the final export at native pixel dimensions for raster artwork, or at its document size for other formats. Check whether key text has missing glyphs, broken lines, or clipping, whether the subject is occluded, and whether the information is complete.
- Visual inspection at placement size. View the finished piece at the intended display or print size and check readability, hierarchy, and cropping. If native and placement sizes coincide, one viewing may support both checks when the dimensions and observations are recorded. If placement size is unknown or cannot be reproduced, mark this check unverified.
- Visual inspection at thumbnail size. Scale the same finished piece to 25% of its width and height and actually view it. When an agreed thumbnail display size exists, use that size. Record the ratio or pixel size, and whether the title is recognizable and the hierarchy between subject and secondary information is clear.
- In the review record (or the verification section of a combined small-task record), state separately for each applicable inspection the file used, how it was viewed, the check items, and the specific observations. When no issues are found, state which items were checked. Link to these observations from the handoff record. For review only, give the evidence in the reply unless a saved record was requested. For any inspection that could not be completed, record the unviewed item as "unverified" with the reason. A successful export, reading pixel dimensions, or computing contrast proves only the corresponding check.
- Check multi-person correspondence, distortion of people or products, logo deformation, temporary placeholders, and unintentionally generated text or marks.
- Check composition and safe areas for each size; for print tasks, check size, resolution, color, and bleed against the confirmed production specs, and do not apply screen output parameters directly.
- When an editable source is agreed, verify that representative text, assets, and layers can be modified. For general export requirements, see [Design File and Export Acceptance](../../standards/quality.md#design-file-and-export-acceptance).

For animated posters, check flashing in the actual export and applicable playback controls on the intended presentation surface per [Core Defaults](../../standards/defaults.md#web-content-and-motion).
